CLI commands

Every command below comes from the current Piper CLI. Prefer the guides for day-to-day use; use this page when you need exact flags.

Global options

FlagDefaultPurpose
--project-rootcwdDirectory that contains .piper/
--outputautoauto, text, or json (auto uses JSON when stdout is not a terminal)
-q / --quietoffErrors only
-v / --verboseoffExtra diagnostics
--no-coloroffDisable colors
--yesoffSkip confirmations (does not choose recovery mode)
--timeout0Overall deadline, for example 30s or 5m

piper inspect

Connect to the source, infer schema, store a snapshot for planning.

example
piper inspect

Flags: connection flags, --run-id, --sample-full (Mongo).

piper plan

Build or reuse a migration plan from the latest schema snapshot. No live target required.

example
piper plan --target mysql

Flags: --target (default postgres), --cycle-mode, --strict-mode, --force, --confirm-relationship, --details, --run-id.

piper execute

Apply the planned schema and data changes to the target.

example
piper execute --yes

Flags: connection flags, --run-id, --upsert (merge|overwrite|fail), --checkpoint (auto|local|target-transactional), --batch-size, --no-ddl, --ddl-only, --recovery, --resume-run, --allow-existing-target.

Constraint

Keep source data unchanged. Piper does not synchronize ongoing changes or guarantee a consistent snapshot.

piper resume

Continue a paused or failed migration from the last checkpoint.

example
piper resume

Flags: connection flags, --run-id.

piper validate

Compare source and target and report differences. Exit 5 on failure.

example
piper validate

piper doctor

Preflight connectivity, compatibility, and safety checks. Warnings alone do not block.

example
piper doctor

Flags: connection flags, --strict-mode, --ledger, --quick, --plan.

piper connect

Test that Piper can reach the source and, when provided, the target.

example
piper connect

piper status

Show state, progress, and latest validation for a run.

example
piper status

piper explain

Show the latest recorded failure and a suggested next step.

example
piper explain

piper runs

List migration runs in this project’s .piper directory. piper runs ls is the same list.

example
piper runs

piper artifacts

List, show, export, or prune run files.

examples
piper artifacts ls
piper artifacts show --path runs/<id>/ir.json
piper artifacts export --run-id <id> --out run.zip
piper artifacts prune --dry-run

prune defaults: --older-than 720h, --keep-last 5. Deletion requires --yes (or use --dry-run to report only).

piper version

example
piper version
piper version -v

Connection flags

Shared by commands that dial databases: --source-url, --target-url, --*-url-file, --*-url-stdin, --no-warn-insecure-flags.

See also Connecting databases and Troubleshooting.
