Install

Piper is one local binary per platform. You do not need a global install, an account, or a package manager.

Pick your platform

Download a binary from the homepage download table, or clone the playground branch for your OS from PiperKitOrg/piper-examples.

PlatformBinaryPlayground branch
macOS Apple Siliconpiper-darwin-arm64darwin-arm64
macOS Intelpiper-darwin-amd64darwin-amd64
Linux x86_64piper-linux-amd64linux-amd64
Linux ARM64piper-linux-arm64linux-arm64
Windows x86_64piper-windows-amd64.exewindows-amd64
Windows ARM64piper-windows-arm64.exewindows-arm64

Checksums: downloads/SHA256SUMS.

Playground (recommended for a first try)

Each platform branch of piper-examples already has the matching binary in bin/. --recurse-submodules pulls the sample datasets. Follow the repo README.md after cloning.

macOS Apple Silicon
git clone --recurse-submodules -b darwin-arm64 https://github.com/PiperKitOrg/piper-examples.git
cd piper-examples
bin/piper version
docker compose up -d
Windows
git clone --recurse-submodules -b windows-amd64 https://github.com/PiperKitOrg/piper-examples.git
cd piper-examples
bin\piper.exe version

Binary alone

Drop the downloaded file anywhere, rename it to piper if you like, and make it executable on macOS or Linux:

command
chmod +x piper-darwin-arm64
mv piper-darwin-arm64 piper
./piper version

Note

Putting Piper on your PATH is optional. Running ./piper from the folder that holds the binary is enough.

Verify the download

Optional, but useful:

command
shasum -a 256 -c SHA256SUMS --ignore-missing
